# Vimora Studio website

Static site for **apps.manojnanjundaswamy.com**, hosted on GitHub Pages.

- `/` studio home, `/untangleart/` app page, `/untangleart/privacy/` privacy policy (use this URL in Play Console)
- `app-ads.txt` for AdMob. Copy it to the root site (manojnanjundaswamy.com) as well.
- `CNAME` sets the custom domain. Cloudflare DNS: CNAME `apps` → `<github-username>.github.io` (DNS only, grey cloud, until GitHub issues the HTTPS certificate).

To add an app: copy `untangleart/`, change the text and icon, and add a card on `index.html`.
